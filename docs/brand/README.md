# Brand assets

## Shelfish

These files are unchanged copies from the Shelfish site pack in SUBCULT Studio
(`subculture-collective/subcult-tv`, `studio/brands/omarchy-plugin-shelfish/`)
at revision `159489c`. The owner accepted the pack on October 13, 2026. The
masters live in Studio. Do not edit these copies; change the pack in Studio and
copy the new files here.

Text in the lockup is converted to paths, so no font is needed. The lockup is
drawn in light colours for dark backgrounds. The README shows it when the
reader's browser requests a dark colour scheme and otherwise shows the one-
colour mark for light backgrounds. The pack has no lockup for light backgrounds.

## SUBCULT wordmark

These light and dark SVG lockups are unchanged copies of the outlined exports
from SUBCULT Studio's selected Culture / poster press brand pack. They preserve
the user-authored mark, geometry and layer order. Outlined text removes the need
for installed fonts. The README chooses the dark version when the reader's
browser requests a dark colour scheme, with the light version as its fallback.

Source: `subcult-studio/branding/2026-10-01-packs/brands/subcult/logos/`.
